# Build the Network, Watch It Run

*A NetSim Field Guide* by Michael Borck.

A practical guide to NetSim: build topologies, configure real Linux syntax, follow packets, test firewalls and services, author auto-graded labs, and export to real systems.

## Structure

- `chapters/`: ten chapters in three parts
- `appendices/`: lab map and check types
- `_quarto.yml`: HTML configuration
